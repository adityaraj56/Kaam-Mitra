## 💡 About the Project
Kaam Mitra is a mobile-first, multilingual digital work passbook and attendance tracking platform designed for India's informal and gig workforce. It bridges the gap between daily wage workers and employers by providing verified work histories, automated wage calculations, and instant payment slip generation.

## 🚀 Core Features
* **Secure Role-Based Access:** Dedicated interfaces for Workers, Employers, Contractors, and Enterprises.
* **Live Attendance & Wage Calculator:** Real-time tracking of Present, Absent, and Holiday statuses with automatic wage computations.
* **Payment Slip Generator:** 1-click professional PDF-ready payslip generation for transparent payouts.
* **Multilingual Support:** Seamless toggling between English and Hindi.

## 💻 Tech Stack
* **Frontend:** HTML5, CSS3, Vanilla JavaScript
* **Database/State Management:** LocalStorage & Google Sheets API integration
* **Deployment:** GitHub Pages (Global CDN hosting)
